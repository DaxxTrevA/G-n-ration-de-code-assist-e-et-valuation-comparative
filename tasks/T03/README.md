# T03 - Additionner un tableau

Implémentez `sumArray(numbers)` dans `submission.js`. La fonction reçoit un
tableau de nombres et renvoie leur somme. Un tableau vide donne `0`. Les
tableaux de test ne contiennent que des nombres finis.

Exemples : `sumArray([2, 3, 5])` renvoie `10` et `sumArray([])` renvoie `0`.

Exportez la fonction avec `module.exports = { sumArray }`.
