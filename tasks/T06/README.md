# T06 - Inverser les mots d'une phrase

Implémentez `reverseWords(text)` dans `submissions/<outil>.js`. La fonction
inverse l'ordre des mots, retire les espaces au début et à la fin, et réduit
toute suite d'espaces à un seul espace. Une chaîne vide ou composée d'espaces
renvoie une chaîne vide.

Exemple : `reverseWords("  bonjour   tout le monde ")` renvoie
`"monde le tout bonjour"`.

Exportez la fonction avec `module.exports = { reverseWords }`.
