# T17 - Trouver un nombre manquant

Implémentez `findMissingNumber(values)` dans `submissions/<outil>.js`. Le
tableau contient les entiers distincts d'un intervalle de 0 à n inclus, avec
exactement une valeur manquante. Retournez cette valeur. Le tableau n'est pas
modifié.

Exemple : `findMissingNumber([3, 0, 1])` renvoie `2`.

Exportez la fonction avec `module.exports = { findMissingNumber }`.
