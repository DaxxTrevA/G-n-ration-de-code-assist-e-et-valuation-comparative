# T08 - Supprimer les doublons en conservant l'ordre

Implémentez `uniqueValues(values)` dans `submissions/<outil>.js`. La fonction
renvoie un nouveau tableau sans doublons, conserve la première occurrence de
chaque valeur, respecte l'égalité utilisée par `Set` en JavaScript et ne
modifie pas le tableau d'origine.

Exemple : `uniqueValues([3, 1, 3, 2, 1])` renvoie `[3, 1, 2]`.

Exportez la fonction avec `module.exports = { uniqueValues }`.
