# T09 - Aplatir un tableau imbriqué

Implémentez `flattenArray(values)` dans `submissions/<outil>.js`. Aplatissez
récursivement tous les tableaux imbriqués dans un nouveau tableau. Conservez
l'ordre des valeurs et le tableau d'origine.

Exemple : `flattenArray([1, [2, [3]], 4])` renvoie `[1, 2, 3, 4]`.

Exportez la fonction avec `module.exports = { flattenArray }`.
