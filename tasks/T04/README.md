# T04 - Compter les voyelles

Implémentez `countVowels(text)` dans le fichier de l'assistant, par exemple
`submissions/copilot.js`. La fonction renvoie le
nombre de voyelles `a`, `e`, `i`, `o`, `u` présentes dans le texte, sans
différencier majuscules et minuscules. Les voyelles accentuées ne sont pas
comptées. Les autres caractères sont ignorés.

Exemples : `countVowels("Bonjour")` renvoie `3` et
`countVowels("Été")` renvoie `0`.

Exportez la fonction avec `module.exports = { countVowels }`.
