# T05 - Générer FizzBuzz

Implémentez `fizzBuzz(n)` dans `submission.js`. Pour un entier `n` positif ou
nul, renvoyez un tableau contenant les valeurs de 1 à `n` : remplacez les
multiples de 3 par `"Fizz"`, ceux de 5 par `"Buzz"` et ceux des deux par
`"FizzBuzz"`. `fizzBuzz(0)` renvoie un tableau vide.

Exemple : `fizzBuzz(5)` renvoie `[1, 2, "Fizz", 4, "Buzz"]`.

Exportez la fonction avec `module.exports = { fizzBuzz }`.
