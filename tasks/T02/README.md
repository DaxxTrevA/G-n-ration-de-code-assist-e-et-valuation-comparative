# T02 - Vérifier un palindrome

Implémentez `isPalindrome(text)` dans `submission.js`. La fonction renvoie
`true` si le texte se lit de la même façon dans les deux sens, sans tenir compte
des majuscules, des espaces ni de la ponctuation. Les caractères accentués
restent distincts de leurs variantes non accentuées. Une chaîne vide est un
palindrome.

Exemples : `isPalindrome("Esope reste ici et se repose")` renvoie `true` et
`isPalindrome("bonjour")` renvoie `false`.

Exportez la fonction avec `module.exports = { isPalindrome }`.
